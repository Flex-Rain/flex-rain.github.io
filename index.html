进程、线程与协程的区别

这是一篇示例笔记，演示你写博客的格式。以后照着这个样子写就行，删掉它也不影响。

面试高频题。三者的核心差异在「调度单位」和「资源拥有者」上。

进程（Process）

  • 资源分配的基本单位，拥有独立的内存空间（代码段、数据段、堆、栈）。
  • 进程间通信（IPC）需要借助管道、共享内存、消息队列等机制，开销大。
  • 切换进程要切换页表、刷新 TLB，代价高。

线程（Thread）

  • CPU 调度的基本单位，同一进程内的线程共享地址空间，只独享寄存器、栈、程序计数器。
  • 线程间通信直接读写共享变量，但要加锁避免竞态。
  • 切换只需保存/恢复寄存器上下文，比进程轻。

协程（Coroutine）

  • 用户态的「轻量级线程」，由程序自己调度，不进内核，切换几乎零成本。
  • 一个线程可以跑成千上万个协程；适合高并发 I/O（如 Go 的 goroutine、Python 的 asyncio）。
  • 本质是「主动让出（yield）+ 恢复」，不需要操作系统介入。

一句话记忆

维度 进程 线程 协程
调度者 操作系统 操作系统 用户程序
是否共享内存 否 是 是
切换开销 大 中 极小

记忆口诀：进程管资源，线程管调度，协程管效率。
